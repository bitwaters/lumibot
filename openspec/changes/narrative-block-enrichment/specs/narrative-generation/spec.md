# narrative-generation Specification

## Purpose
LLM 叙事生成规则与确定性链接提取：叙事句 ≤100 字覆盖 6 维、只引用真实数据；链接由代码从 token_info `link` 对象提取，绝不由 LLM 生成。

## ADDED Requirements

### Requirement: Rich six-dimension narrative sentence
The narrative sentence MUST be generated by the LLM within 100 characters, covering up to six dimensions when information is available: 1) theme/concept, 2) positioning/source (official project / community takeover / copycat, launch platform), 3) community heat signals, 4) risk cues (new dev address, holder concentration, taxes, dev behaviour), 5) developer background (prior token creation count), 6) smart-money / rat-trader signals. Dimensions with insufficient information MUST be omitted. Real data (symbol, name, description, website, launch platform, creator history, rat/bundler ratios, smart-wallet counts) MUST be injected into the LLM prompt, and the prompt MUST instruct the model to reference only the given numbers and never fabricate numbers or links.

#### Scenario: Full-information token
- **WHEN** a token has description, platform and risk data
- **THEN** the narrative sentence covers the relevant dimensions within 100 characters without fabricated figures

#### Scenario: Info-poor token with links
- **WHEN** a token lacks description data but has social links
- **THEN** the model returns N/A for the sentence, and the block renders only the `🔗` link line

#### Scenario: Info-poor token without links
- **WHEN** a token lacks both description and social data
- **THEN** no narrative block is rendered (unchanged fail-open)

#### Scenario: No fabricated numbers
- **WHEN** the prompt includes real metric values
- **THEN** the sentence may reference only those values; a fabricated number is treated as a prompt violation and rejected (output discarded on N/A or failed validation)

### Requirement: Deterministic link extraction
Links MUST be extracted by code from the token_info `link` object, never generated by the LLM. Each link type MUST render as a short label hyperlink, separated by `·` on a single `🔗` line, first value per type winning (deduplicated): `X` for twitter_username (`https://x.com/{username}`, username validated against `[A-Za-z0-9_]{1,15}`), `官网` for website, `TG` for telegram (`社区` instead when `dev.cto_flag` is set), and `DC` / `YT` / `IG` / `TT` for discord / youtube / instagram / tiktok. All links MUST be hyperlinks; spoofed domains are surfaced by the Telegram click-confirmation dialog which displays the full URL. Invalid or missing values MUST be omitted. The `gmgn` and `geckoterminal` fields MUST be skipped.

#### Scenario: Valid X username
- **WHEN** link.twitter_username is a valid handle
- **THEN** the link line contains `X` as a hyperlink to `https://x.com/RealTrump`

#### Scenario: Multiple links one line
- **WHEN** a token has X, website and telegram links
- **THEN** the `🔗` line renders `X · 官网 · TG` with each label hyperlinked and `·` separators

#### Scenario: CTO community label
- **WHEN** dev.cto_flag is set and a telegram link exists
- **THEN** the telegram label renders as `社区` instead of `TG`

#### Scenario: Malformed username
- **WHEN** link.twitter_username contains injection characters, exceeds 15 chars, or is a tweet URL path
- **THEN** the X link is omitted entirely

### Requirement: Narrative block layout
The narrative block MUST render as: a `📚` line with the narrative sentence (wrapping to at most two lines) followed by a `🔗` line with the extracted links, when any link exists. The block MUST be the last text lines of the card (signal push cards and CA query cards alike). The block MUST be HTML-escaped and MUST remain valid HTML. The narrative sentence MUST have domain-like tokens de-autolinked (zero-width space after the dot) so Telegram clients render them as plain text; the link line's hyperlinks MUST NOT be altered.

#### Scenario: Signal card with links
- **WHEN** a signal card receives its async narrative edit and the token has social links
- **THEN** the edited card ends with the `📚` sentence line and a `🔗` link line

#### Scenario: No links
- **WHEN** a token has no social links
- **THEN** the block contains only the `📚` sentence line

#### Scenario: Links without sentence
- **WHEN** the LLM returns N/A but social links exist
- **THEN** the async edit still fires and the card ends with only the `🔗` link line

#### Scenario: HTML validity
- **WHEN** the block is rendered
- **THEN** it passes the card HTML well-formedness guard (hyperlinks included)
